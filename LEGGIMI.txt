PUBBLICARE SU GITHUB PAGES
1. Crea un repository su GitHub e carica TUTTO il contenuto di questa cartella (index.html, manifest.json, sw.js, data.json, cartella icons).
2. Settings > Pages > Source: "Deploy from a branch" > branch main, cartella /root > Save.
3. Apri l'indirizzo https://TUONOME.github.io/NOMEREPO/ (da telefono: "Aggiungi a schermata Home" per installarla).

COME FUNZIONANO I DATI (importante)
- Non c'è un server: l'admin modifica i dati sul proprio dispositivo.
- Per farli vedere a tutti: Area personale > Gestione > Impostazioni > "Scarica data.json",
  poi su GitHub sostituisci il file data.json nel repository (Add file > Upload files). Dopo 1-2 minuti tutti vedono gli aggiornamenti.
- La prima volta crei l'account admin (tocca l'omino). Scarica e carica subito data.json,
  così l'account vale anche da altri dispositivi.
- Fai sempre l'accesso admin dallo stesso dispositivo, oppure importa data.json prima di modificare.

CONTROLLARE LA VERSIONE
In fondo a ogni pagina c'è scritto "Oratorio San Michele · v3". Se non vedi "v3", il browser sta mostrando una vecchia copia:
verifica di aver sostituito index.html e sw.js su GitHub e ricarica con Ctrl+F5 (PC).

LOGO
Il logo non è più incorporato: caricalo da Area personale > Gestione > Impostazioni > Carica logo.
